# 📊 Fundamentos de Linguagem Python Do Básico a Aplicações de IA

Repositório com todos os exercícios, estudos de caso e mini-projetos do meu curso gratuito de **Fundamentos de Linguagem Python Do Básico a Aplicações de IA**.

Meu objetivo é construir uma base sólida em Python, montar um portfólio de projetos reais e conquistar uma vaga como **analista de dados**.

> 🚧 Repositório em construção: eu faço commits a cada etapa concluída.

---

## 🎯 Sobre o curso

O curso leva do zero absoluto até a criação de soluções de IA, sempre aprendendo na prática, com projetos que simulam o dia a dia de um profissional de dados.

**O que estou estudando:**

- **Fundamentos de Python:** lógica de programação, funções e Programação Orientada a Objetos
- **Ciência de Dados:** NumPy, Pandas, Matplotlib e Statsmodels
- **Machine Learning:** modelos de classificação e análise de sentimentos
- **Deep Learning:** redes neurais com PyTorch
- **IA Generativa:** LLMs e RAG com LangChain
- **Agentes de IA:** automação com CrewAI, Groq e Tavily
- **Data Apps:** dashboards interativos com Streamlit
- **MLOps:** noções de deploy e operação de modelos

## ▶️ Como executar um projeto

1. Clone o repositório:
   ```bash
    git clone https://github.com/Judoloko/analista-de-dados.git
   ```
2. Entre na pasta do projeto que quiser ver:
   ```bash
    cd analista-de-dados
   ```
3. Instale as bibliotecas necessárias (cada projeto terá o seu `requirements.txt`):
   ```bash
    pip install -r requirements.txt
   ```
4. Execute o arquivo principal:
   ```bash
    python nome_do_arquivo.py
   ```
